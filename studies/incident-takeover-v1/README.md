状态：实现与机制对照完成；本提交冻结模型、源码、镜像和预算，尚未调用模型。
[计划](plan.json)规定一次 Sol max 完整交互，150 动作、单次请求 600 秒、整轮 3600 秒。
模型只收到客户症状、业务目标和普通终端入口，没有事故操作菜单或评估器 verify。

四个已执行的机制对照中：不处置不能恢复；只改路由仍缺少旧分支 45 条已确认订单；
实际执行 pg_rewind 也不会合并这 45 条业务记录；按业务引用合并并重映射关联记录可以完整恢复并通过重启检查。
这些是已知解法的制品对照，只证明机制和可行性，不证明高难度或盲测策略能力。

模型结果将完整保留，不静默重试或替换失败。成功则否定该候选的高难度证据资格；
失败则先审计因果、可得信息和运行环境，不能把基础设施故障归因于认知能力。

[提前断流](../stream-delivery-http-retry-v1/README.md)、
[业务恢复后事件拒绝](../stream-delivery-transport-retry-v1/README.md)。最后一次的
业务状态正确，但正式交接未完成，不能事后改成成功。

2.17.3 允许不承载动作的新增流式元数据，审计事件名称与数量；未完成或无效调用、
越界工具、明确模型错误和完成后的事件仍会拒绝。273 项离线测试及修改前后各两轮
正常原生接口检查通过。后者没有复现上次的未知事件，也不代表事故能力结果。

[计划](plan.json)在调用前冻结：同一 GPT-6 Astra `max`、事故与镜像、客户策略、
业务验收、200 动作、每次网络尝试 600 秒、整轮 10800 秒、最多两次有限传输重试。
一次独立运行，不增加恢复提示，不做人工救援，不更换模型或降低推理强度。

本次完整通过：[结果](model-result.md)为 `delivered`，终止原因为 `finished`。
模型自行执行 16 个终端动作后调用 `finish`；动作计数仅用于预算与审计。
独立验收在真实重启后确认 84 个订单、60 笔发货全部正确，12/12 新客户需求
均被履行并得到确认。订单、回执、新命令、漏发、重复发货、多余发货、已发货内容
修改及观察器/重试协议错误均为零。后台写失败为零。

已报告输入 641,104 token、输出 14,930 token，合计 **656,034 token**。
其中 4,948 reasoning token 是输出的子集，不再额外相加。17 次网络尝试均有 usage
报告；缓存输入量和实际费用未知。整轮 **689.879012 秒**包含环境准备、模型运行
和独立验收。客户批次确认上界为 15.769945 或 28.03866 秒，不是逐请求或发货延迟。

本轮没有触发传输重试，也没有收到被忽略的新增元数据事件。完整真实 provider
轨迹验证了这次集成能够正常交付；新增元数据兼容性仍由本地 HTTP 反例夹具验证。
此前事件拒绝的具体类型没有保留，本轮成功不能证明其精确原因已经复现或消除。
